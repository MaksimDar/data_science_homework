## Description

A collection of Jupyter Notebook assignments covering foundational data science workflows — data loading, cleaning, exploratory data analysis, and visualization — applied to several public datasets. Each notebook (`Hw1` through `Hw5`, including sub-parts `Hw2.1`–`Hw2.3`) corresponds to a separate homework assignment completed as part of a Data Science coursework track.

## Tech Stack

- **Python** (Jupyter Notebook)
- **pandas** / **NumPy** — data manipulation and analysis
- **Matplotlib** / **Seaborn** *(where applicable)* — data visualization

## Datasets

| File | Typical use case |
|---|---|
| `2017_jun_final.csv` | Developer salary survey data — pandas fundamentals, filtering, and aggregation |
| `Housing.csv` | Housing price data — exploratory analysis and regression |
| `bikes_rent.csv` | Bike rental demand data — regression and feature analysis |
| `bestsellers_with_categories.csv` | Amazon bestseller book data — categorical data analysis |
| `python_data.csv` | General-purpose dataset for pandas practice |

## Functionality

Each notebook addresses a self-contained assignment, generally involving:
- Loading and inspecting a dataset with pandas.
- Cleaning and preparing data for analysis.
- Computing descriptive statistics and exploring relationships between variables.
- Visualizing findings with charts and plots.

Refer to the individual notebook files for the specific task requirements and solutions.

## Installation & Usage

```bash
git clone https://github.com/MaksimDar/data_science_homework.git
cd data_science_homework

pip install pandas numpy matplotlib seaborn jupyter
jupyter notebook
```

Open any of the `Hw*.ipynb` files to view the corresponding assignment.
